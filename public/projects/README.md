# Project cover images

Drop a screenshot here named after each project's slug and it will replace the
generated cover automatically:

- `netrasetu.png`
- `aura.png`
- `truesource.png`
- `echotrace.png`
- `aegis.png`

Recommended: ~1200×900 (4:3), PNG or JPG. If a file is missing, the site shows
a generated dark cover with the project's icon and name instead.
